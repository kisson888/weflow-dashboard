========================================
  WeFlow 监控看板 — 使用说明
========================================

外部版本: v2.0 | 内部版本: v33 | 更新: 2026-05-31

========================================
一、快速开始
========================================

1. 确保 WeFlow 桌面端已安装并正在运行
   确保 WeFlow 的 HTTP API 服务已开启（默认端口 5031）

2. 双击 start.vbs（推荐，无窗口后台运行）
   或 双击 启动看板.bat（有命令行窗口）

3. 首次运行自动进入安装向导：
   第 1 步：设置登录密码（至少 4 位）
   第 2 步：配置 WeFlow API 地址（默认 http://127.0.0.1:5031）和 Token
   第 3 步：选择数据目录（默认安装目录下的 data/ 子目录）
   第 4 步：点击「进入看板」

4. 浏览器打开 http://127.0.0.1:8765
5. 输入密码进入看板


========================================
二、功能说明
========================================

【总览】— 监控概览：总会话数、总消息数、监控/待监控状态一目了然
【会话管理】— 添加/移除候选会话，启用/禁用监控，设置备份计划
【手动执行】— 勾选会话后执行全量/增量/区间导出，查看执行日志
【日报浏览】— 自动生成的每日聊天摘要
【数据浏览】— 浏览已导出的 JSON 记录
【HTML 聊天】— 格式化聊天记录浏览，含日期分割线和发送者名称
【设置】— WeFlow 连接、修改密码、查看版本信息、停止服务


========================================
三、常见问题
========================================

Q: 打不开 http://127.0.0.1:8765？
A: 确认 WeFlowDashboard 进程在运行（任务管理器查看）。

Q: 导出显示 0 条？
A: 检查 WeFlow 是否在运行，API Token 是否正确。

Q: 导出很慢卡住？
A: 会话消息量大时按 500 条/批自动分批拉取，等待即可。

Q: 如何停止服务？
A: 双击「停止服务.bat」，或在网页「设置」页点「停止服务」。

Q: 版本号怎么区分的？
A: 外部版本（v2.0）面向用户，大版本更新时递增；
   内部版本（v26）面向开发，每次构建自动递增，用于测试对比和问题定位。


========================================

本看板（WeFlow Dashboard）是一个纯后端可视化工具，本身不收集、不存储、
不传输任何聊天数据。所有展示的聊天记录均来源于 WeFlow 的 HTTP API 推送。

聊天数据的准确性、完整性和时效性由 WeFlow 及微信客户端决定。
任何因聊天记录引发的隐私、法律或合规问题，责任由 WeFlow 的使用者承担。
本看板仅作为数据展示和管理的后端工具，不承担数据来源相关责任。
建议使用者在使用前确保已获得相关会话成员的知情同意。
