📖 使用说明


      

        
关于本看板

        

          WeFlow 监控看板是一个基于 WeFlow HTTP API 的微信聊天记录管理与可视化工具。
          支持全量/增量/区间导出，自动生成日报和 HTML 格式聊天记录。
        

      


      

        
页面功能

        
    
          
  • 总览 — 查看所有会话的监控状态、消息数和同步情况，监控中/待监控一目了然
    • 
          
  • 会话管理 — 添加/移除候选会话，启用/禁用监控，设置备份计划，快捷导出清空
    • 
          
  • 手动执行 — 选择会话后执行全量/增量/区间导出，查看执行日志
    • 
          
  • 日报浏览 — 查看自动生成的每日聊天摘要
    • 
          
  • 数据浏览 — 浏览已导出的 JSON 聊天记录文件
    • 
          
  • HTML 聊天 — 以格式化 HTML 方式浏览聊天记录，含日期分割线和发送者名称
    • 
          
  • 设置 — 配置 WeFlow 连接、修改密码、查看系统版本信息
    • 
        

      


      

        
定时导出

        

          每个会话可独立配置备份计划（每天/每周/每月），设定具体时间和频率。
          区间导出支持按日期范围导出历史消息，并带有自动重试和断点续传机制。
        

      


      

        
发送者名称解析说明

        

          显示名称优先级：备注名 > 群昵称 > 微信昵称 > displayName。
          需要 WeFlow 的 HTTP API 处于运行状态才能正确解析。
        

      


      

        
⚠️ 重要声明

        

          本看板（WeFlow Dashboard）是一个纯后端可视化工具，本身不收集、不存储、不传输任何聊天数据。
          所有展示的聊天记录均来源于 WeFlow 的 HTTP API 推送。
        

        
    
          
  • 聊天数据的准确性、完整性和时效性由 WeFlow 及微信客户端决定
    • 
          
  • 任何因聊天记录引发的隐私、法律或合规问题，责任由 WeFlow 的使用者承担
    • 
          
  • 本看板仅作为数据展示和管理的后端工具，不承担数据来源相关责任
    • 
          
  • 建议使用者在使用前确保已获得相关会话成员的知情同意
    • 
        

      


      

        
版本说明

        

          外部版本（v2.0）面向用户，大版本更新时递增。

          内部版本（v26）面向开发，每次构建自动递增，用于测试对比和问题定位。
        

      


      

        
技术信息

        

          
后端框架：Python 3 标准库（零外部依赖）

          
前端样式：Tailwind CSS (CDN)

          
打包方式：PyInstaller 打包为独立 exe，无需 Python 运行环境

          
启动脚本：启动看板.bat（显示控制台）/ start.vbs（静默启动）
