# 2026-05-31 工作记录

## 修复 WeFlow Dashboard 5个已知问题

### 1. 手动执行页左侧会话列表不同步会话管理页
- **文件**: `dashboard.html`
- **修改**: `loadActionsSessions()` 改为从 `state.config.sessions` 获取监控会话（而非从 `/api/status`），确保与会话管理页完全同步

### 2. 总览页会话状态显示"已禁用"而非"待监控"
- **文件**: `dashboard.html`
- **修改**: `renderOverview()` 中 `已禁用` → `待监控`，`toggleSession()` 中 Toast 提示 `已禁用` → `已关闭`

### 3. 全量导出转圈（关键Bug修复）
- **文件**: `dashboard_server.py`
- **根因**: `/api/run/quick` 错误地将 `run_export_threaded()` 的返回值（dict）再次包装，导致前端 `export_id` 变成对象而非字符串，进度轮询 `prog.export_id !== exportId` 永远匹配失败
- **修改**: `/api/run/quick` 直接返回 `run_export_threaded()` 的结果（与其他端点 `/api/run/full`、`/api/run/manual-incr` 保持一致）

### 4. 区间导出为0 + 断点续传
- **文件**: `dashboard_server.py`、`dashboard.html`
- **修改**: 新增 `run_range_export_threaded()` 使区间导出也使用线程模式+进度轮询+0条自动重试；前端 `doQuickRange()` 和 `runRangeExport()` 改为使用进度弹窗+轮询

### 5. 区间导出弹窗"最早"和"今天"位置优化
- **文件**: `dashboard.html`
- **修改**: `showQuickRange()` 将开始日期和结束日期分开布局，各自下方放置对应的快捷按钮（"最早"在开始日期下方，"今天"在结束日期下方）
